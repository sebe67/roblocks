# Sourced audio

Real audio you've picked (not synthesized placeholders — see
`../placeholder/` for those), tracked here so it's in version control
before you upload it, same as any other repo asset. Still needs uploading
through Studio/the Creator Dashboard yourself and the resulting
`rbxassetid://...` pasted into `Config.lua` — nothing here reaches the game
automatically.

| File | Goes in |
|---|---|
| `jumpscare_scream.mp3` | `Config.Sounds.JumpscareScream` — the shared fallback every monster's jumpscare currently uses (see that field's comment in `Config.lua`) |
